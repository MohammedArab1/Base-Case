# 150 Essential Problems Extension Pack

This is an optional bundled pack. It stays off until a user enables it in
**Settings → Content packs**.

The pack adds the 88 coding problems that are not already covered by the core
pack for the 150 Essential Problems study list. Its collection uses the same
`groupId` as the core collection, so the app merges both into one filter:
62 core problems by default, or all 150 when this pack is enabled.

Every statement, example, hint, test, and reference solution here is original
to Base Case. The study-list attribution and source link live in `pack.json`.
The app is not affiliated with or endorsed by NeetCode.
