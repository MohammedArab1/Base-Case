# Duplicate Check

Return whether any value appears at least twice in `nums`.

## Input

- `nums`: a list of integers.

## Output

`true` if a value repeats, otherwise `false`.

## Examples

**Example 1**

```
Input: nums = [8,1,4,1]
Output: true
```

**Example 2**

```
Input: nums = [7,2,9,3]
Output: false
```

**Example 3**

```
Input: nums = []
Output: false
```

**Example 4**

```
Input: nums = [5]
Output: false
```

**Example 5**

```
Input: nums = [2,3,2]
Output: true
```

## Constraints

- `0 <= nums.length <= 100,000`
- `-1,000,000,000 <= nums[i] <= 1,000,000,000`

## Follow-up

Can you solve it by sorting, and what trade-off does that make?
