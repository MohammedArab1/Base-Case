# Design template

1. Copy this folder to `content/packs/<pack>/designs/<slug>/`.
2. Rename the folder, `slug`, and `id`.
3. Rewrite the prompt, requirements, scale, and follow-ups.
4. Keep the rubric at seven dimensions. Make every level concrete and observable.
5. Draw the reference design in Excalidraw and export/save the scene JSON.
6. Write the reference document: data flow, storage, scaling, failure handling, trade-offs.
7. Run `pnpm content:validate` from the repository root.
