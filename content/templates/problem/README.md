# Problem template

1. Copy this folder to `content/packs/<pack>/problems/<slug>/`.
2. Rename the folder, `slug`, `id`, and method names.
3. Rewrite every file. The placeholder solution intentionally throws.
4. Add 3–5 sample tests and 15–50 hidden tests. Each JSONL line is one test.
5. Verify every expected output with at least two independent solutions.
6. Run `pnpm content:validate` from the repository root.
7. Ask a second person to review the statement for ambiguity and originality.
